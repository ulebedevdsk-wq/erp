# erp
Штаб запуска 1С:ERP (штамповочный завод) — рабочие веб-страницы на GitHub Pages.

- `/` — точка входа штаба ERP: кнопки на дашборды (QR, GLPI, проблемные банки, штаб), форму заявок и хелпдеск: https://ulebedevdsk-wq.github.io/erp/
- `/prod/` — форма заявок производства (проблемы ERP с участков и складов, тикеты в GLPI): https://ulebedevdsk-wq.github.io/erp/prod/
- `/old/` — первая форма заявок (август 2026), не используется с 02.09.2026

Как поменять кнопку на точке входа: открыть `index.html`, найти блок `<a class="card" ...>`, поменять адрес в `href`, заголовок и описание (подробнее — в комментарии в начале файла).
